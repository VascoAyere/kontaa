# Kontaa

Every sale counted. Receipts, sales and who owes you, for Ghanaian shops.

Live app: https://vascoayere.github.io/kontaa/

- One self-contained `index.html` (works offline once loaded).
- Each receipt is a locked PDF with a verification code.
- Send by WhatsApp, SMS or email from the phone's share menu.
- All shop data stays on the shop's own phone (browser storage); nothing is uploaded.
